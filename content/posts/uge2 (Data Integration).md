# Uge 2 - Data Integration

## Fokus denne uge

I denne uge var fokus på data integration og på, hvordan quiz-systemet kan hente data fra en ekstern kilde i stedet for kun at bruge data, der er oprettet lokalt.

## Hvad jeg lavede

Jeg undersøgte muligheden for at hente quizspørgsmål fra et eksternt API og arbejde videre med dem i mit eget system. Det gav anledning til at tænke over, hvordan data fra en ekstern kilde kan konverteres til de objekter og den struktur, som mit eget program bruger.

## Hvad jeg lærte

Jeg fik en bedre forståelse for forskellen mellem dataformatet i et eksternt API og programmets egne Java-klasser. Jeg arbejdede derfor med idéen om, at data først skal hentes, læses og derefter mappes over i de objekter, som resten af programmet arbejder med.

## Udfordringer og overvejelser

En vigtig overvejelse var, at quiz-systemet ikke skulle være for tæt koblet til én bestemt datakilde. Hvis jeg senere vil skifte API eller selv oprette spørgsmål, bør resten af programmet helst ikke skulle ændres ret meget.

## Refleksion

Ugen gjorde det tydeligt for mig, at data integration ikke kun handler om at hente data. Det handler også om at tilpasse data til sit eget system og tænke over, hvordan løsningen kan holdes fleksibel.
